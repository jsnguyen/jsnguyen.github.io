# Project instructions

This repository contains my personal website.

- Keep changes targeted, minimal, readable, and simple.
- Preserve the existing code style and website design unless I ask for changes.
- Prefer small edits over complete rewrites.
- Keep function arguments on one line unless they are extremely long.
- Ask before making large changes or introducing new dependencies.
- Match the style and prose of existing text.
- Avoid em-dashes and excessive hyphenation.
- Your adjustments should be modular and easily removable from the code.
- Separate your changes into separate files so I can easily toggle and remove them if needed.
- Do not take stylistic liberties, abide by the current styles and rules and general design philosophy of the existing code.
